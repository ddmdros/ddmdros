## Hi, I'm Diogo Medeiros 👋

Software Engineering student who builds LLM agents and uses them in production. I have six years of experience in game localization, two of them in-house in Dublin. In 2026 I designed a multi-agent harness in Python that translates and reviews games for real clients, with a human making the final call on every delivery. It took my throughput from about 300 to about 900 words per hour.

## AI projects

- **[agent-harness](https://github.com/ddmdros/agent-harness)**: the open core of that harness. Python guards decide where each agent may write, a queue holds the decisions an agent made on its own for human approval, and reviewer output is merged by a fixed rule. It also measures session cost in tokens. Tested on Linux and Windows.
- **[rag-gta](https://github.com/ddmdros/rag-gta)**: local RAG with Ollama and Chroma. Three retrieval modes (similarity, MMR and multi-query) and an evaluation set that scores retrieval, answers and refusals. Built with [Stephanie Pinho](https://github.com/stephanielumertz).
- **[Netplay](https://github.com/ddmdros/Netplay)**: FastAPI agent with tool calling for a peer-to-peer game marketplace, migrated to LangChain 1.x, with tests and CI. Built with [Stephanie Pinho](https://github.com/stephanielumertz).
